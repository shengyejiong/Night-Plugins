# 多特战役难度选项

SourceMod 战役难度插件，提供可由全体玩家在游戏内切换的功能：

- **AI Tank 投石后重瞄**：石头离手后清除 AI Tank 的旧朝向锁定，使其恢复追踪当前生还者。仅作用于 AI Tank，不改变真人 Tank 视角，不扩大拳头范围，也不会自动命中。
- **Hunter 空中防推**：阻止未扑到人的 Hunter 在特定空中受击动作中被幸存者推开。
- **AI Hunter 跳扑增强**：仅强化 AI Hunter 的连续跳扑、空中前进与跳扑视角微调；不包含全局特感强攻逻辑。
- **AI Smoker 主动伸舌增强**：AI Smoker 对可见的当前目标进行胸口瞄准，并在舌头有效距离内主动尝试伸舌。没有连跳、传送或强制改目标逻辑。
- **Smoker 舌头立即吊起修复**：Smoker 舌头刚抓住生还者时刷新落地时间，避免仍在地面附近的生还者被错误判定为悬空并立即进入吊起/窒息状态。对真人和 AI Smoker 均生效。
- **特感推击踉跄方向修复**：幸存者推中特感时，将特感动画状态的偏航校准到当前实际朝向，再由游戏按原生推击向量执行踉跄，避免动画朝错误或相反方向播放。只处理特感被幸存者推击，不改变生还者受到的其他踉跄。
- **Charger 倒地连拳伤害**：将 Charger 正在锤击其倒地抓取目标时的每次伤害固定为 **30**。对真人和 AI Charger 都生效；不影响冲撞、撞飞或普通爪击。
- **Tank / Charger 推击减速修复**：幸存者推击 Tank 或 Charger 时不再令其减速。对真人和 AI 均生效。
- **Tank 近战反制**：幸存者每次用普通近战命中 Tank，都会同时提前 Tank 主攻击和副攻击的可用时间。对真人和 AI Tank 都生效，且**无叠加上限**。
- **Tank 石头空爆与延迟补偿**：回溯幸存者开枪时看到的石头位置，以枪械属性计算石头伤害；石头累计受到 100 点伤害后空爆。对真人和 AI Tank 的石头均生效。
- **Tank 战水中不减速**：任一 Tank 存活时，幸存者在水中按正常跑速移动；最后一只 Tank 死亡后恢复原本的水中减速，并向聊天栏提示。不会改动 Tank 水中速度、枪火减速或蹲伏速度。
- **Tank 一拳致倒击飞**：Tank 一拳将幸存者打倒时，保留原生的击飞位移，使倒地者更容易脱离 Tank 的近身补拳范围。未启用跳过落地动画的做法，因此不会让落地者提前开枪。
- **普通感染者推击修复**：修复普通感染者在蹲伏、下落、落地和爬梯状态下无法正常被推的问题。四种状态由同一个菜单开关控制。
- **重复/遗漏起身修复（多人）**：采用 `l4d2_getup_fixes` 的完整修复逻辑，处理 Hunter、Smoker、Jockey、Charger、Tank 拳/石头之间交叉导致的重复起身、遗漏起身或起身状态卡住。状态按客户端槽位保存，重复角色和 4 人以上均可独立工作；玩家与 Bot 接管时会迁移状态。

默认状态：AI Tank 投石后重瞄、Smoker 舌头立即吊起修复、特感推击踉跄方向修复、Tank / Charger 推击减速修复、Tank 石头空爆与延迟补偿、Tank 战水中不减速、Tank 一拳致倒击飞、普通感染者推击修复、重复/遗漏起身修复（多人）**开启**；其余选项**关闭**。

## 安装

1. 将 [l4d2_campaign_difficulty_options.smx](/D:/download/插件/自找插件/服务器增加难度插件/多特战役难度选项/l4d2_campaign_difficulty_options.smx) 放入服务器的 `left4dead2/addons/sourcemod/plugins/`。
2. 将 [l4d2_getup_fixes.txt](/D:/download/插件/自找插件/服务器增加难度插件/多特战役难度选项/left4dead2/addons/sourcemod/gamedata/l4d2_getup_fixes.txt)、[l4d_fix_common_shove.txt](/D:/download/插件/自找插件/服务器增加难度插件/多特战役难度选项/left4dead2/addons/sourcemod/gamedata/l4d_fix_common_shove.txt)、[l4d_fix_stagger_dir.txt](/D:/download/插件/自找插件/服务器增加难度插件/多特战役难度选项/left4dead2/addons/sourcemod/gamedata/l4d_fix_stagger_dir.txt) 和 [actions.games.txt](/D:/download/插件/自找插件/服务器增加难度插件/多特战役难度选项/left4dead2/addons/sourcemod/gamedata/actions.games.txt) 放入服务器的 `left4dead2/addons/sourcemod/gamedata/`。
3. 将 [actions.autoload](/D:/download/插件/自找插件/服务器增加难度插件/多特战役难度选项/left4dead2/addons/sourcemod/extensions/actions.autoload) 和 [actions.ext.2.l4d2.so](/D:/download/插件/自找插件/服务器增加难度插件/多特战役难度选项/left4dead2/addons/sourcemod/extensions/actions.ext.2.l4d2.so) 放入服务器的 `left4dead2/addons/sourcemod/extensions/`。这是普通感染者推击修复所需的 Linux Actions 扩展；若服务器已有同名文件，请先备份并确认版本，不能同时放两套 Actions 扩展。
4. 确保服务器已安装并加载 `left4dhooks.smx`。4.2.0 起，本插件自身不再依赖 Source Scramble；如果其他插件仍使用它，不要从服务器全局删除该扩展或管理器。
5. 完整重启服务器，让 Actions 扩展加载；随后用 `sm exts list` 和 `sm plugins list` 检查加载状态。

> 不要与旧版 `l4d2_no_hunter_deadstops.smx` 同时加载；旧版没有本插件的总开关，会导致 Hunter 空中防推始终生效。

首次加载后会生成配置文件：

`left4dead2/cfg/sourcemod/l4d2_campaign_difficulty_options.cfg`

若你安装过旧版，建议删除这个自动生成的 CFG 后完整重启，让 4.4.0 重新生成配置项。旧的 `l4d2_difficulty_zombie_spawn_fix` 即使残留也不会再被读取。

## 游戏内菜单

所有已进入游戏的玩家均可在聊天栏输入：

```text
!tankdiff
```

打开菜单，调整会立即影响整台服务器。

## 配置项

```cfg
// 1=开启 AI Tank 投石后重瞄，0=关闭
l4d2_difficulty_smart_ai_rock "1"

// 1=开启 Hunter 空中防推，0=关闭
l4d2_difficulty_hunter_no_deadstop "0"

// 1=开启 AI Hunter 跳扑增强，0=关闭
l4d2_difficulty_ai_hunter_pounce "0"

// 1=开启 AI Smoker 主动伸舌增强，0=关闭
l4d2_difficulty_ai_smoker_tongue "0"

// 1=修复 Smoker 舌头刚抓住生还者时异常立即吊起，0=关闭
l4d2_difficulty_tongue_float_fix "1"

// 1=修复特感被幸存者推击时的踉跄动画方向，0=关闭
l4d2_difficulty_si_shove_direction_fix "1"

// 1=将 Charger 对倒地抓取目标的每次锤击伤害设为30，0=关闭
l4d2_difficulty_charger_incap_pummel "0"

// 1=幸存者推击不减速 Tank 和 Charger，0=关闭
l4d2_difficulty_tank_charger_shove_fix "1"

// 1=近战命中 Tank 时无上限提前其主、副攻击冷却，0=关闭
l4d2_difficulty_tank_melee_fury "0"

// 1=开启 Tank 石头空爆与延迟补偿，0=关闭
l4d2_difficulty_rock_lagcomp "1"

// 1=任一 Tank 存活时幸存者水中不减速，0=关闭
l4d2_difficulty_tank_water_no_slowdown "1"

// 1=Tank 一拳致倒时击飞幸存者，0=关闭
l4d2_difficulty_tank_flying_incap "1"

// 1=修复普通感染者蹲伏、下落、落地和爬梯时无法正常被推，0=关闭
l4d2_difficulty_common_shove_fix "1"

// 1=启用完整的多人重复/遗漏起身修复，0=关闭
l4d2_difficulty_multi_getup_fix "1"

// Charger 较长起身动画相关设置；仅影响起身修复开启时
l4d2_difficulty_getup_long_charger_godframe "2.2"
l4d2_difficulty_getup_keep_wall_slam "1"
l4d2_difficulty_getup_keep_long_charge "0"
```

石头功能还提供下列高级配置，默认值与参考插件一致；一般不需要改动：

```cfg
l4d2_difficulty_rock_hitbox_radius "30"
l4d2_difficulty_rock_godframes "1.7"
l4d2_difficulty_rock_godframes_render "1"
l4d2_difficulty_rock_range_min "1"
l4d2_difficulty_rock_range_max "2000"
```

通过菜单切换任一选项后，所有开关的状态会保存到：

`left4dead2/addons/sourcemod/data/l4d2_campaign_difficulty_options_state.cfg`

因此换图、重载插件或重启服务器后，所有菜单选项都会保持最后一次菜单选择。删除该状态文件即可恢复各项默认值（AI Tank 投石后重瞄、Smoker 舌头立即吊起修复、特感推击踉跄方向修复、Tank / Charger 推击减速修复、Tank 石头空爆与延迟补偿、Tank 战水中不减速、Tank 一拳致倒击飞、普通感染者推击修复、重复/遗漏起身修复（多人）开启；其余选项关闭）。

## 与 `!x` 多特菜单共存

`!x` 通过加载或卸载 `specialspawner`，并修改 `ss_*` 刷特数量、批次和时间参数来控制多特。本插件 4.2.0 已删除特感生成稳定修复，不再修改任何 `zombie_spawn_fix` 内存补丁，因此与 `!x` 没有这方面的交叉。

如果你希望服务器也彻底停用旧刷新修复，必须继续把 `left4dead2/addons/sourcemod/configs/sourcescramble/zombie_spawn_fix.txt` 留在 `configs/sourcescramble/` 目录外；否则 `sourcescramble_manager.smx` 会独立启用它，与本插件是否删除该功能无关。

## 与“特感主动攻击”插件共存

AI Hunter 跳扑增强不带 `nb_assault` 等全局强攻指令，只改 AI Hunter 的按键与空中动作；AI Smoker 主动伸舌增强只改 AI Smoker 的瞄准和技能按键。因此两项都可与 `aggresive_specials_patch` 一同使用。不要额外加载整份 `AI_HardSI_new.smx`，否则会把 Tank、Jockey、Spitter 和全局强攻逻辑也带入。

## 来源说明

AI Tank 投石后重瞄逻辑基于 `Smart AI Rock`（Forgetest、CanadaRox），并合并为本插件的独立开关。

AI Smoker 主动伸舌增强参考 `ai_smoker_new`，但只保留瞄准和主动伸舌逻辑；原插件的连跳、传送和目标策略未合并。

Smoker 舌头立即吊起修复参考 `l4d_tongue_float_fix`（Forgetest），只在成功抓住生还者时刷新舌头技能实体的落地计时；不要再同时加载独立 `l4d_tongue_float_fix.smx`。

特感推击踉跄方向修复参考 `l4d_fix_stagger_dir`（Forgetest），仅整合 `L4D_OnShovedBySurvivor` 的特感推击路径，没有带入原插件对生还者通用踉跄的 `L4D2_OnStagger` 修改；依赖同名 gamedata。不要再同时加载独立 `l4d_fix_stagger_dir.smx`。

Charger 倒地连拳伤害逻辑参考 `charger_incap_damage`（Sir、A1m`），并固定为每次 30 伤害。

Tank / Charger 推击减速修复逻辑参考 `l4d2_tank_charger_m2_fix`（Sir、Visor）。

Tank 近战反制逻辑参考 `l4d2_tank_melee_fury`（Visor），保留了其主、副攻击同时提前且无上限叠加的行为。

Tank 石头空爆与延迟补偿逻辑参考 `l4d_rock_lagcomp`（Luckylockm、harry、Silvers、AnneHappy）。不要与独立的 `l4d_rock_lagcomp.smx` 同时加载，否则会重复改写石头受弹和空爆判定。

Tank 战水中不减速逻辑参考 `l4d2_slowdown_control`（Lux），仅保留 Tank 存活期间幸存者水中不减速，以及 Tank 死亡后恢复和聊天提示。

Tank 一拳致倒击飞逻辑参考 `l4d2_tank_flying_incap`（Sir、Forgetest），已改为逐名幸存者保存倒地状态和按游戏 Tick 判断，未合并原插件的动画跳过修复。

普通感染者推击修复参考 `l4d_fix_common_shove`（Forgetest），保留蹲伏、下落、落地和爬梯四种修复并合并为一个默认开启的持久化开关；依赖 Actions 扩展和同名 gamedata 文件。不要再同时加载独立 `l4d_fix_common_shove.smx`。

重复/遗漏起身修复参考 `l4d2_getup_fixes`（Forgetest），已将完整修复逻辑纳入统一菜单，并按客户端槽位保存 Charger 关联状态。不要同时加载旧版 `double_getup.smx` 或独立 `l4d2_getup_fixes.smx`，否则会重复修改同一套起身动画状态。
