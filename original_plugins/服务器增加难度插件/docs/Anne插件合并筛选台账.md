# Anne 插件合并筛选台账

更新：2026-11-17。目标是把选定的修复、加难和减难功能并入 Night-Plugins 的 `!tankdiff` 主插件。每项用独立的全服菜单开关，继续保存到现有状态文件；做完一项后再单独标记「已合并」。台账的结论不代表已经改代码或上服。

- 对照基线：本库 `!tankdiff 4.4.13` 的[完整源码](../addons/sourcemod/scripting/l4d2_campaign_difficulty_options.sp)和 2026-10-28 VPS 运行快照。VPS 快照里同名 `.sp` 与实际 `.smx` 不对应，移植以库版完整源码为起点。
- 范围：Anne 本地副本 `c6b201e1` 的通用修复、Anne 共用、普通药役和硬核药役配置中实际写有加载指令的插件，去重后再加三项补查。未执行服务器配置；配置中写了加载不代表线上实测加载成功。这里不是整个 Anne 包或 GitHub 最新版的清单。
- 筛选规则：先查是否已有同类功能，再看能否靠事件或现有回调完成；有游戏签名、底层扩展、持续扫描或会接管刷怪／导演的项目，要先验证依赖和冲突。暂缓项目仍可复查。
- 战役服优先：主要服务真人 Tank 或对抗模式的机制先跳过；不把原生数值调整当作修复。
- 更新提醒：等用户明确说要上传时，再说明更新步骤及所需文件；筛选过程中不重复提醒。
- 更新方式：从「待筛选」移到「已筛选」时写清功能、现有覆盖、开销／依赖和决定；落地后补版本与测试结果。没有复现或没对完源码的项目保留在「待筛选」。
