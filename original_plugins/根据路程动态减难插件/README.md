# 根据路程动态减难

作者：night  
版本：1.8.3-night

根据本章团灭次数和团灭路程，通过全员投票分五阶降低难度。第一阶在后续每次团灭重开时按真人数量生成止痛药；第二阶会在最近五次有效团灭的平均路程处复活死亡真人；第三阶会把同一复活效果提升为满血复活；第四阶会让复活者随机获得一件医疗物资；第五阶会在路程复活后只剩一名存活生还者时再次复活死亡真人。没有主武器的存活真人还可通过指令自行领取一把随机基础主武器。

## 游戏内指令

- `!fd`：所有玩家均可查看团灭次数、最近五次团灭、阶段和投票状态。
- `!flowassist_status`：与 `!fd` 相同。
- `!flowassist`：打开主动减难阶段投票菜单；所有真人均可发起，管理员选择后直接开启，普通真人选择后由在线真人投票决定。
- `!flowassist_vote`：与 `!flowassist` 相同。
- `!fa`：与 `!flowassist` 相同。
- `!fr <0-100>`：所有真人都可以把本回合复活目标路程临时改为指定百分比。
- `!gun`：打开随机基础主武器领取菜单。
- `!sg`：与 `!gun` 相同。
- `!flowassist_reset`：高级管理员清空当前章节的计数和减难状态。

## 注意事项

- 需要 Left 4 DHooks；减难投票使用 SourceMod 左侧菜单，不再依赖 `l4d2_nativevote`。
- 默认第一阶、第二阶、第三阶、第四阶、第五阶投票门槛分别为 2 次早期团灭、5 次、7 次、9 次和 11 次总团灭。
- 主动阶段菜单可以直接选择任意尚未开启的最高阶段，并自动依次排队前置阶段投票。
- 投票开始时在线的真人会各自收到左侧菜单，可选择同意、反对、弃权或退出；弃权和退出不计入同意率分母。
- 同意率按 `同意 ÷（同意 + 反对）` 计算，必须严格超过 60% 才能通过；任何 SourceMod 管理员投反对票都会直接否决本次投票。
- 连续 3 次团灭无法取得路程时进入导航备用模式；总团灭达到 4 次可触发第一阶，依赖路程的第二、三阶暂停。
- 导航异常地图可在 `addons/sourcemod/configs/l4d2_flow_difficulty_maps.cfg` 中禁用路程功能或覆盖最大 Flow 距离。
- 随机基础主武器中，鸟狙占 10%，木喷、铁喷、UZI 和消音冲锋枪各占 22.5%；玩家选择领取时已经拥有主武器不会发放。
- 每名玩家每回合最多成功领取一次，团灭重开后恢复资格；打开菜单、取消或因已有主武器未能领取均不会消耗资格。
- 指令整回合可用，但仅限存活的真人生还者；发枪后会按服务器当前对应弹药上限补满备弹。

## 1.5.0-night 更新

- 将三阶减难投票改为普通 SourceMod 左侧菜单：1 同意、2 反对、3 弃权、4 退出。
- 弃权、退出、菜单超时和菜单被打断均按弃权处理，不会阻止投票结算。
- 同意率必须严格超过 60%，计算分母只包含同意票和反对票。
- 任意 SourceMod 管理员投反对票都会触发最高否决权，投票直接失败。
- 移除 `l4d2_nativevote` 依赖，继续使用现有投票时长配置。
