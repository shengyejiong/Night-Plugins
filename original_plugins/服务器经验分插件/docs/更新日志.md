# L4D2 多特经验分插件更新日志

本文档记录 `l4d2_multisi_experience` 的主要功能变化，方便服务器管理和玩家理解每一版加了什么。

---

## v1.7.0 - 新增大枪持用时间衰减

- 新增按玩家、按枪种独立记录的大枪持用时间衰减。
- 参与衰减的枪种：M16、SCAR、AK47、15 连狙、30 连狙、Scout 和 AWP。
- 不参与衰减：现有小枪、两把连喷、手枪、近战、M60、榴弹发射器、投掷物和爆炸类武器。
- 当前拿在手上的受限枪种每秒累计 `1` 秒，其他已使用过的受限枪种按恢复倍率逐秒回退。
- 同一枪种共享时间，丢枪后换一把同类武器不会重置；不同枪种拥有各自独立的时间。
- 默认前 `120` 秒保持完整时间倍率，`120-420` 秒线性衰减，到 `420` 秒时该枪种的伤害分时间倍率为 `0`。
- 时间衰减叠加在原武器倍率之后，只影响特感和 Tank 的计分伤害；原始伤害、击杀、清控、技巧、命中率和其他事件分不受影响。
- `!mexp_round` 新增 `[武器]` 行，显示当前枪种累计时间与时间倍率；持有豁免武器时显示恢复中时间最高的枪种。
- 每关开始、重新开启本图计分或重新开启衰减功能时清空枪种时间。
- 使用换枪回调和时间戳按需计算，不使用每秒 Timer，也不增加 `OnGameFrame` 处理。
- 新增配置：
  - `l4d2_mexp_weapon_decay_enable "1"`
  - `l4d2_mexp_weapon_decay_start "120.0"`
  - `l4d2_mexp_weapon_decay_zero "420.0"`
  - `l4d2_mexp_weapon_decay_recovery_rate "1.0"`
- 插件作者字段按当前项目要求更新为 `night`。
- 同步 README 到最新服务器 CFG：特杀 `0.2`、小尸 `0.14`、Tank 伤害 `0.003`、两把连喷倍率 `0.8`。

## v1.6.7 - 新增个人经验分排名

- 玩家主动输入 `!mexp` 时，新增显示服务器经验分排名。
- 排名只发送给查询者，不加入玩家进服时的全服经验播报。
- 排名查询时动态扫描经验存档，不在 data 文件中保存容易过期的固定排名字段。
- 默认至少需要 `5` 个有效关卡才会上榜。
- 未达到门槛时显示“暂未上榜”，但仍会正常显示经验分和有效关卡数。
- 排名按聊天框显示的整数经验分计算，同分玩家并列。
- 新增配置：`l4d2_mexp_rank_min_rounds "5"`，设为 `0` 可让所有存档记录参与排名。

- 不设置独立技巧分上限，技巧分仍会经过现有高分压缩和本关总分硬上限。
- `!mexp_round` 新增两行 `[技巧]`，显示七项次数和技巧加分。
- 新增配置：
  - `l4d2_mexp_w_skeet "1.0"`

## v1.6.5 - 新增终点阶段安全屋外事故保护

- 新增终点阶段安全屋外事故保护。
- 新增配置：
  - `l4d2_mexp_endgame_outside_death_guard "1"`
  - `l4d2_mexp_endgame_outside_death_negative_scale "0.50"`
- 有任意玩家进入终点安全屋后，若其他玩家在安全屋外倒地/死亡，会记录为终点阶段安全屋外事故。
- 本关倒地/死亡扣分仍正常计算，不会让本关分变好看。
- 如果最终成功过关，该玩家本关若会掉长期经验，只吃配置倍率的掉分影响。
- 如果该玩家本来会涨长期经验，正常涨。
- 如果最终团灭，不触发保护。
- `!mexp_round` 在触发后会额外显示 `[终点]` 行，方便测试。

## v1.6.4 - 新增成功过关低分保护

- 新增成功过关低分保护，用来缓解简单图、怪少图过关后全队低分导致长期经验普遍下降的问题。
- 新增配置：
  - `l4d2_mexp_win_low_team_score_floor "180.0"`
  - `l4d2_mexp_win_low_score_negative_scale "0.25"`
- 只在 `map_transition` 和 `finale_win` 成功过关时触发。
- `mission_lost` 团灭不触发。
- 触发条件为有效玩家团队均分低于阈值。
- 保护只降低“掉长期分”的影响，不降低正常加分。
- 没有加入“安全屋外死亡减免”，因为插件无法可靠区分主动找特感自杀和真实没防住被控死。

## v1.6.1 - 紧急修复经验档案被默认值覆盖

- 修复严重问题：玩家刚进入服务器时，如果 SteamID 尚未完成认证，插件可能先按默认值 `1000` 经验、`0` 有效关卡初始化。
- 旧逻辑会把这种“默认初始化状态”误认为已经成功读取档案，之后玩家断开、换图或保存时，可能把 data 中原有记录覆盖成 `1000/0`。
- 现在只有在成功拿到 SteamID，并且成功读取 data 文件后，才会标记为“已加载，可保存”。
- 如果 SteamID 暂时拿不到，插件不会播报默认经验，也不会保存覆盖旧档。
- 如果 data 文件存在但读取失败，保存会被跳过，并写入 SourceMod error log，避免用空数据覆盖整个经验文件。
- 本次不新增 cfg 参数。

## v1.6.0 - 新增短图长期经验保护

- 新增短图保护机制：短图仍然播报本关评分，但会降低或跳过长期经验变化。
- 新增配置：
  - `l4d2_mexp_short_round_skip_time "300.0"`
  - `l4d2_mexp_short_round_full_time "600.0"`
  - `l4d2_mexp_short_round_min_weight_scale "0.25"`
- 本关时长低于 `300` 秒时，只播报本关评分，不更新长期经验，也不增加有效关卡数。
- 本关时长在 `300-600` 秒之间时，长期经验影响倍率从 `25%` 逐渐提高到 `100%`。
- 本关时长达到 `600` 秒后，正常使用完整 `l4d2_mexp_rating_weight`。
- 触发短图保护时，结算播报会提示“长期经验不变”或“长期经验影响倍率”。
- 该功能只影响长期经验迭代，不改变本关临时评分和 `!mexp_round` 的统计展示。

## v1.5.2 - 新增游戏内计分开关指令

- 新增管理员指令 `!mexp_enable`。
- 直接输入 `!mexp_enable` 会打开左侧菜单，可选择开启、关闭或切换计分状态。
- 支持快速输入：
  - `!mexp_enable 0`：关闭本图计分。
  - `!mexp_enable 1`：开启本图计分。
  - `!mexp_enable toggle`：切换当前状态。
  - `!mexp_enable status`：查看当前状态。
- 指令会修改同一个配置项 `l4d2_mexp_enable`，因此仍然遵守 v1.5.1 的逻辑：关闭后不记录、不结算、不保存本图经验变化。
- 该指令需要 SourceMod 管理员的 cvar 管理权限。

## v1.5.1 - 完善本图计分开关

- 强化已有配置 `l4d2_mexp_enable` 的实际效果。
- 设置为 `0` 后，本图不会记录统计、不会结算、不会保存长期经验变化。
- 运行中从 `1` 改为 `0` 时，会清空当前本关统计，避免坑图、机关图、测试图污染长期经验分。
- 运行中从 `0` 改回 `1` 时，会从当前时间重新开始记录。

## v1.4.1 - 修复本关统计指令不显示

- 修复 `!mexp_round` 在聊天框没有反馈的问题。
- 原因是本关统计字段越来越多，单条 `PrintToChat` 消息过长，游戏聊天框可能整条不显示。
- 现在将本关统计拆成多条短消息：
  - `[本关]`：评分、命中率、小尸、特感伤害、特杀。
  - `[输出]`：Tank、Witch、石头相关数据。
  - `[状态]`：清控、承压、救人、被控、倒地、死亡。
  - `[失误]`：Tank 拳、打铁、口水、友伤。

## v1.4.0 - 有效命中率小额奖励

  - `l4d2_mexp_accuracy_step "0.10"`

- 近战、投掷物、榴弹等不计入命中率统计。

- 武器倍率不影响清控、救人、承压、小僵尸击杀、特感尾刀击杀等事件分。

## v1.0.x - 基础经验分版本

- 建立本关评分与长期经验分系统。
- 回合结束后按本关表现结算经验分。
- 玩家进服后可在聊天框全服播报长期经验分。
- 支持 `!mexp` 查看长期经验分。
- 支持 `!mexp_round` 查看本关临时统计。
- 默认不统计 Bot，默认至少 2 个有效真人才结算。
- 结算时机包括正常过关、团灭、终局胜利。
- 避免投票重启、强制换图等不完整游玩污染经验分。
- 已有基础统计项：
  - 特感伤害
  - 特感击杀
  - 清控
  - 救人
  - 电击复活
  - 承压
  - 被控次数
  - 被控时间
  - 倒地
  - 死亡
  - 友伤
- 长期经验分使用缓慢迭代，不是无限累加。
