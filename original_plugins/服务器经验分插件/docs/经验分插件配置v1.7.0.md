# L4D2 多特经验分评定插件

当前文档版本：`1.7.0`

`l4d2_multisi_experience` 是一个面向《求生之路 2》多人多特战役服的经验分评定插件。它不是单纯按击杀数排名，而是综合统计玩家在一关中的输出、救控、救人、承压、倒地、死亡和友伤，再把本关表现缓慢写入长期经验分。

插件目标是给服务器提供一个相对稳定的“玩家综合表现参考”，方便玩家了解自己的长期水平，也方便服务器展示玩家经验。

---

## 主要功能

- 回合结束时播报本关经验分评定。
- 玩家进服后，在左下角聊天框向全服播报该玩家长期经验分。
- 玩家可输入 `!mexp` 查看自己的长期经验分。
- 玩家可输入 `!mexp_round` 查看本关临时统计。
- 管理员可输入 `!mexp_enable` 打开计分开关菜单，或用 `!mexp_enable 0/1` 快速切换。
- 长期经验分保存到 `addons/sourcemod/data/l4d2_multisi_exp.txt`。
- 默认不统计 Bot，避免电脑影响榜单。
- 默认至少 2 个有效真人才结算，防止单人带电脑刷分。
- 可以用 `l4d2_mexp_enable` 临时关闭整张图计分，适合坑图、机关图、测试图。
- 短图会自动降低或跳过长期经验变化，避免几分钟结束的小图过度影响长期分。
- `1.6.1` 修复了玩家刚进服时 SteamID 尚未认证完成，可能把旧经验覆盖成默认 `1000/0` 的严重问题。
- `1.6.2` 扩展了武器伤害倍率，可对 M16、SCAR、AK、连喷和狙击枪单独调整伤害分效率。
- `1.6.3` 将 `!mexp_round` 中的特感伤害和 Tank 伤害显示为“原始伤害(计分伤害)”，避免武器倍率造成误解。
- `1.6.4` 新增成功过关低分保护：团队均分偏低时，只降低掉长期分的影响，不影响正常加分。
- `1.6.5` 新增终点阶段安全屋外事故保护：有人进终点安全屋后，安全屋外倒地/死亡者若最终过关，只降低长期掉分影响。
- `1.6.6` 新增生还者技巧性动作奖励，接入 `l4d2_skill_detect` 的空爆、砍舌、推停、秒牛、秒救和 Smoker 自救事件。
- `1.6.7` 新增个人经验分排名，只在玩家主动输入 `!mexp` 时显示，不加入进服播报。
- `1.7.0` 新增按玩家、按枪种独立累计的大枪持用时间衰减，限制长时间使用步枪和狙击枪刷伤害分。

## 玩家指令

| 指令 | 作用 |
| --- | --- |
| `!mexp` | 查看自己的长期经验分、有效关卡数和服务器个人排名。 |
| `!mexp_round` | 查看本关当前临时评分、输出、状态、失误、技巧性动作和大枪时间衰减状态；伤害显示格式为“原始伤害(计分伤害)”。 |
| `!mexp_enable` | 管理员指令；打开左侧菜单，选择开启/关闭本图计分。 |
| `!mexp_enable 0` | 管理员指令；关闭本图计分。 |
| `!mexp_enable 1` | 管理员指令；开启本图计分。 |
| `!mexp_enable toggle` | 管理员指令；切换当前计分状态。 |
| `!mexp_enable status` | 管理员指令；查看当前计分状态。 |

## 个人经验分排名

从 `1.6.7` 开始，玩家主动输入 `!mexp` 时，会在个人聊天框中看到服务器经验分排名：

```text
[经验] 玩家A 当前经验分：1889，有效关卡：92
[排名] 服务器经验分排名：13/286
```

排名规则：

- 排名只发送给查询者，不会在玩家进服时向全服播报。
- 排名在查询时动态读取 `addons/sourcemod/data/l4d2_multisi_exp.txt`，不会把容易过期的排名字段写进存档。
- 默认至少需要 `5` 个有效关卡才会上榜。
- 未达到门槛时显示“暂未上榜”，但仍会正常显示经验分和有效关卡数。
- 按聊天框中显示的整数经验分排名；显示分数相同的玩家并列。
- 排名格式为“当前名次/符合上榜条件的玩家总数”。

相关配置：

```cfg
l4d2_mexp_rank_min_rounds "5"
```

设为 `0` 时，所有存档记录都可以参与排名，包括有效关卡为 `0` 的记录。

## 进服播报

玩家连接服务器后，默认延迟 5 秒在左下角聊天框向全服显示：

```text
[经验] 玩家名 加入服务器，当前经验分：1000，有效关卡：0。
```

相关配置：

```cfg
l4d2_mexp_join_announce "1"
l4d2_mexp_join_announce_delay "5.0"
```

## 插件计分开关

从 `1.5.1` 开始，`l4d2_mexp_enable` 会作为真正的“本图不计分开关”使用。
从 `1.5.2` 开始，管理员可以通过 `!mexp_enable` 直接在游戏内切换，不需要手动输入 `sm_cvar`。

```cfg
l4d2_mexp_enable "1"
```

含义：

- `1`：正常记录本关数据，过关或团灭时按规则结算并写入长期经验分。
- `0`：不记录本关统计，不结算，不保存长期经验变化。
- 关闭期间使用 `!mexp_round`，会提示当前地图经验分计分已关闭。
- 运行中从 `1` 改成 `0` 时，会清空当前已经累计的本关统计。
- 运行中从 `0` 改回 `1` 时，会从当前时间重新开始记录本关统计。

适合关闭的情况：

- 坑图、机关图。
- 关闭多特后娱乐游玩。
- 频繁死亡、频繁重开、测试插件或测试地图。

注意：

- 这是普通 cvar，设成 `0` 后会持续生效，直到再次设回 `1`。
- 如果你用地图 cfg 关闭某些图，建议在正常图或默认 cfg 中明确写回 `l4d2_mexp_enable "1"`。
- 它不会删除已有长期经验存档，只是不让当前地图继续影响长期经验。

游戏内管理员指令：

```text
!mexp_enable
!mexp_enable 0
!mexp_enable 1
!mexp_enable toggle
!mexp_enable status
```

说明：

- 不带参数时，会在左侧打开菜单。
- 带 `0` 时关闭计分，带 `1` 时开启计分。
- 需要 SourceMod 管理员权限，使用的是 cvar 管理权限。

如果不想进服播报，把 `l4d2_mexp_join_announce` 改成 `0`。

## 结算时机

插件会在以下情况结算本关分数：

- 正常过关进入下一小关：`map_transition`
- 团灭：`mission_lost`
- 终局胜利：`finale_win`

插件不会使用泛用的 `round_end` 事件结算，目的是避免投票重启、管理员强制重启、强制换图等未完整游玩的情况污染经验分。

## 有效玩家条件

默认配置：

```cfg
l4d2_mexp_include_bots "0"
l4d2_mexp_min_players "2"
```

含义：

- Bot 不参与评分、排行和长期经验。
- 至少 2 个有效真人才会结算。
- 1 个真人 + 3 个电脑测试时不会结算。

参与时间要求：

```text
min(120 秒, max(15 秒, 本关时长 * 0.5))
```

对应配置：

```cfg
l4d2_mexp_min_play_time "120.0"
l4d2_mexp_min_play_ratio "0.5"
l4d2_mexp_min_play_floor "15.0"
```

也就是说，一名玩家需要参与本关足够长时间，才算有效玩家。

## 本关评分算法

当前服务器配置使用 600 分硬上限，并在 350 分以上进行软上限压缩：

```cfg
l4d2_mexp_score_min "0.0"
l4d2_mexp_score_max "600.0"
l4d2_mexp_score_softcap "350.0"
l4d2_mexp_score_softcap_scale "0.5"
```

基础公式：

```text
本关分 =
  基础分
  + 特感伤害 * 特感伤害权重
  + 特感击杀 * 特杀权重
  + 小僵尸击杀 * 小僵尸权重
  + 清控次数 * 清控权重
  + 救人次数 * 救人权重
  + 电击复活次数 * 电击权重
  + 承压次数 * 承压权重
  + Tank 伤害 * Tank 伤害权重
  + Tank 击杀 * Tank 击杀权重
  + 单只 Tank 最高伤次数 * Tank 最高伤权重
  + Witch 击杀 * Witch 击杀权重
  + 打爆 Tank 石头次数 * 石头打爆权重
  + 有效命中率奖励
  + 生还者技巧性动作奖励
  - 被控次数 * 被控次数惩罚
  - 被控秒数 * 被控时间惩罚
  - 倒地次数 * 倒地惩罚
  - 死亡次数 * 死亡惩罚
  - 安全屋内倒地/死亡惩罚减免
  - 友伤伤害 * 友伤惩罚
  - 被 Tank 石头命中次数 * 石头命中惩罚
  - 站立时吃 Tank 拳次数 * Tank 拳惩罚
  - 站立时被 Tank 打铁压中次数 * Tank 打铁惩罚
  - 站立时受到口水伤害 * 口水伤害惩罚
```

高分段压缩公式：

```text
如果原始分 <= score_softcap：
  最终分 = 原始分

如果原始分 > score_softcap：
  最终分 = score_softcap + (原始分 - score_softcap) * score_softcap_scale

最后再限制到 score_min / score_max 范围内。
```

当前配置下，350 分以上的额外分数只按 50% 计入。例如原始分 400 会压缩为 375，原始分 500 会压缩为 425。这样可以减少多人同时顶满硬上限的情况。

### 分数理解

大致可以按下面理解，实际还要看地图、人数、特感刷新和团队节奏：

| 本关分 | 粗略含义 |
| --- | --- |
| 100 以下 | 死得早、倒地多、参与度低，或本关出现严重失误。 |
| 100-180 | 正常参与，但贡献或生存表现偏低。 |
| 180-260 | 普通到良好表现。 |
| 260-340 | 表现优秀，对团队有明显帮助。 |
| 340-430 | 很强的发挥，通常需要高输出、少失误，并有救控/承压/救人贡献。 |
| 430-520 | 非常突出的发挥，通常出现在高压关卡、高贡献输出或多项团队贡献叠加时。 |
| 520-600 | 极高贡献表现，已经接近当前硬上限。 |

## 长期经验分算法

长期经验不是简单累加，不会无限上涨。它使用缓慢迭代：

```text
目标经验 = 本关分 * 10
实际权重 = 基础权重 * 短图倍率
新经验 = 旧经验 * (1 - 实际权重) + 目标经验 * 实际权重
```

当前 cfg：

```cfg
l4d2_mexp_default_rating "1000.0"
l4d2_mexp_rating_weight "0.006"
```

因为本关最高分是 600，所以长期经验大致会向 `0-6000` 区间靠近。`0.006` 表示每个有效关卡只影响长期经验的 0.6%，长期分变化会更慢，不会因为几关发挥不好就剧烈掉分。

举例：

```text
旧经验 2000，本关 140 分
目标经验 = 1400
新经验 = 2000 * 0.994 + 1400 * 0.006 = 1996.4
```

如果想让长期分变化更慢，可以把 `l4d2_mexp_rating_weight` 改成 `0.005`。如果想让新数据更快反映，可以改成 `0.015` 或更高。

## 短图保护

从 `1.6.0` 开始，插件会根据本关实际时长降低长期经验影响，避免特别短、特别简单的小图因为样本太少导致全员扣分。

```cfg
l4d2_mexp_short_round_skip_time "300.0"
l4d2_mexp_short_round_full_time "600.0"
l4d2_mexp_short_round_min_weight_scale "0.25"
```

当前逻辑：

- 少于 `300` 秒：只播报本关评分，不更新长期经验，也不增加有效关卡数。
- `300-600` 秒：更新长期经验，但实际权重从 `25%` 逐渐提高到 `100%`。
- 大于等于 `600` 秒：正常使用完整 `l4d2_mexp_rating_weight`。

举例：

- 4 分钟过关：显示本关评分，但长期经验不变。
- 7 分钟过关：长期经验会变化，但影响比正常图小。
- 10 分钟以上过关：按正常权重更新长期经验。

结算播报时，如果触发短图保护，会额外提示“长期经验不变”或“长期经验影响倍率”。

这个功能只影响长期经验迭代，不会改变 `!mexp_round` 看到的本关临时评分，也不会改变结算时展示的本关分。

## 过关低分保护

从 `1.6.4` 开始，插件会在成功过关时检查团队均分。如果团队均分偏低，说明这张图可能比较简单、怪少、得分机会少，此时不会强行给本关加分，而是降低“掉长期经验”的影响。

```cfg
l4d2_mexp_win_low_team_score_floor "180.0"
l4d2_mexp_win_low_score_negative_scale "0.25"
```

当前逻辑：

- 只在 `map_transition` 和 `finale_win` 成功过关时触发。
- `mission_lost` 团灭不会触发。
- 只看有效玩家的团队平均本关分。
- 团队均分低于 `180` 时，如果某个玩家本关会掉长期经验，只吃 `25%` 掉分影响。
- 如果某个玩家本关会涨长期经验，仍然正常加分，不会被这个保护压低。

举例：

- 成功过关，团队均分 `150`，某玩家本来会掉 `20` 长期分：实际大约只掉 `5`。
- 成功过关，团队均分 `150`，某玩家本来会涨分：正常涨。
- 团灭，团队均分再低也不触发这个保护。

这个功能主要解决“简单图全队分数都低，过关却普遍掉长期分”的问题。它不判断玩家是否故意在安全屋外死亡，也不会给安全屋外死亡额外减免。

结算播报时，如果触发保护，会提示团队均分和本关掉分影响倍率。

## 终点阶段安全屋外事故保护

从 `1.6.5` 开始，插件会记录“终点阶段安全屋外倒地/死亡”。它不是判断玩家是否故意自杀，而是判断这次事故是否发生在队伍已经进入收尾阶段。

```cfg
l4d2_mexp_endgame_outside_death_guard "1"
l4d2_mexp_endgame_outside_death_negative_scale "0.50"
```

当前逻辑：

- 只要有任意有效玩家进入终点安全屋，就标记为“终点阶段”。
- 终点阶段内，某个玩家如果不在终点安全屋内，并且发生倒地或死亡，就记为“终点安全屋外事故”。
- 本关倒地/死亡仍正常记录，`!mexp_round` 会额外显示 `[终点] 安全屋外倒地 / 安全屋外死亡`。
- 本关评分仍正常扣倒地/死亡分，不会因为这个保护变好看。
- 如果最终 `map_transition` 或 `finale_win` 成功过关，该玩家本关如果会掉长期经验，只吃 `50%` 掉分影响。
- 如果该玩家本来会涨长期经验，正常涨。
- 如果最终 `mission_lost` 团灭，不触发保护。

和安全屋内倒地/死亡倍率的关系：

- 安全屋内倒地/死亡仍按 `l4d2_mexp_saferoom_incap_scale` / `l4d2_mexp_saferoom_death_scale` 计算本关分。
- 终点安全屋外事故保护只影响长期经验的负向更新倍率。
- 这两套逻辑互不覆盖。

这个功能用于缓解“队伍已经进门收尾，但外面血少玩家死亡导致长期经验被重锤”的情况；它不会免除本关死亡扣分，也不会奖励主动死亡。

## 关键统计解释

### 特感伤害

玩家对普通特感造成的伤害。当前只统计 Smoker、Boomer、Hunter、Spitter、Jockey、Charger，不统计 Tank。

从 `1.3.0` 开始，特感伤害权重提高、尾刀击杀权重降低。当前配置为特感伤害 `0.01`、尾刀击杀 `0.2`，更偏向奖励真正打出伤害的人，减少“人头被最后一枪抢走”带来的分数差。

### 特杀

玩家击杀普通特感的次数。当前尾刀分保留为少量加分，用来认可补枪和收尾，但它不再是特感输出分的主要来源。

### 武器伤害倍率

武器倍率会调整伤害类得分效率。倍率只影响“特感伤害”和“Tank 伤害”的计分值，不影响清控、救人、承压、击杀次数、小僵尸击杀、命中率奖励等事件分。

从 `1.6.3` 开始，`!mexp_round` 会同时显示原始伤害和计分伤害：

```text

```

括号外是游戏原始伤害，方便和游戏内直觉对齐；括号内是套用武器倍率后的计分伤害，实际加分使用括号内数值。

### 大枪持用时间衰减

从 `1.7.0` 开始，M16、SCAR、AK47、15 连狙、30 连狙、Scout 和 AWP 会按本关持用时间追加一层伤害分衰减。该功能用来限制长时间站在中后排持续使用步枪或狙击枪刷取伤害分，同时保留短时间拿枪应急和换枪调度的空间。

计时规则：

- 每位玩家、每个枪种分别记录，不同玩家互不影响。
- 同一枪种共享计时；丢掉旧 AK 再拿一把新 AK 不会清空 AK 的时间。
- 当前把受限枪种拿在手上时，该枪种每秒累计 `1` 秒。
- 换成其他枪种后，原枪种按每秒 `1` 秒回退；多个未使用枪种可以同时恢复。
- 换到另一种受限枪时，新枪种从自己的剩余时间开始累计，旧枪种继续恢复。
- 每关开始、重新开启本图计分或重新开启衰减功能时清空全部枪种时间。

当前默认区间：

```cfg
l4d2_mexp_weapon_decay_enable "1"
l4d2_mexp_weapon_decay_start "120.0"
l4d2_mexp_weapon_decay_zero "420.0"
l4d2_mexp_weapon_decay_recovery_rate "1.0"
```

- `0-120` 秒：时间倍率为 `1.0`，不额外衰减。
- `120-420` 秒：时间倍率从 `1.0` 线性下降到 `0.0`。
- 达到 `420` 秒：该枪种后续造成的特感和 Tank 伤害仍记录原始值，但不再产生伤害分；换枪恢复后可以重新获得伤害分。

计算公式：

```text
最终计分伤害 = 原始伤害 × 原武器倍率 × 持用时间倍率
```

例如 AK47 已累计 `300` 秒，时间倍率为 `(420 - 300) / (420 - 120) = 0.40`。当前 AK 基础倍率为 `0.87`，因此最终伤害分倍率为 `0.87 × 0.40 = 0.348`。换用 M16 `60` 秒后，AK 会恢复到 `240` 秒，再换回 AK 时，时间倍率回升为 `0.60`。

不参与时间衰减的武器：

- Uzi、消音 SMG、MP5、SG552、木喷和铁喷。
- 一代连喷和二代连喷 / SPAS。
- 手枪、马格南、近战、M60、榴弹发射器、投掷物和爆炸类武器。

时间衰减仍然只影响特感伤害分和 Tank 伤害分，不影响特感尾刀、小尸击杀、清控、救人、承压、技巧、命中率、Tank 击杀与 `坦一`。`!mexp_round` 会显示当前枪种的累计时间和时间倍率；拿着不衰减武器时，会显示恢复中剩余时间最高的枪种。

实现采用换枪回调和时间戳按需补算，不使用每秒循环计时器，也不增加 `OnGameFrame` 高频处理。

### 有效命中率

从 `1.4.0` 开始，插件会统计本关有效命中率，并给予很小的额外加分。

当前规则：

- 只统计枪械类武器，不统计近战、投掷物、榴弹等。
- 必须达到最低开火次数才会计算奖励，当前为 `80` 次。
- 低于 `10%` 命中率不加分。
- `10%-20%` 命中率加 `1` 分。
- `20%-30%` 命中率加 `2` 分。
- 后续每提高 `10%` 命中率，多加 `1` 分。
- 命中率奖励最高为 `8` 分。

相关配置：

```cfg
l4d2_mexp_w_accuracy_step "1.0"
l4d2_mexp_accuracy_min_shots "80"
l4d2_mexp_accuracy_floor "0.10"
l4d2_mexp_accuracy_step "0.10"
l4d2_mexp_accuracy_max_bonus "8.0"
```

注意：这个功能是小额奖励，不是核心评分项。设计目的只是认可稳定命中和有效输出，避免鼓励玩家为了刷命中率而少开枪。

### 生还者技巧性动作

从 `1.6.6` 开始，经验分插件会接收 `l4d2_skill_detect.smx` 提供的技巧事件，并给予小额奖励：

| 技巧动作 | 单次加分 |
| --- | ---: |
| 完整霰弹空爆 Hunter | `1.0` |
| 近战空爆 Hunter | `2.0` |
| 近战砍断 Smoker 舌头 | `0.5` |
| 推停正在飞扑的 Hunter | `0.2` |
| 近战秒杀 Charger | `0.2` |
| `0.75` 秒内救下被控队友 | `0.8` |
| 从 Smoker 控制中自救 | `0.6` |

说明：

- 近战秒牛不区分满血秒杀和残血近战收尾，两种都会计数。
- 秒救只奖励救队友，个人自救不会记成秒救。
- 秒救的 `0.8` 分是原有清控分之外的速度奖励，不会额外增加一次清控次数。
- 团队合力空爆无法可靠归属个人，不计入个人完整空爆次数。
- Bot 默认由 `l4d2_mexp_include_bots "0"` 排除。
- 技巧奖励没有独立上限，但会和其他项目一起经过高分段压缩以及本关总分硬上限。
- `!mexp_round` 会用两行 `[技巧]` 显示各项次数和当前技巧加分。
- `l4d2_skill_detect.smx` 未加载时，经验分插件的其他功能仍可使用，但技巧次数会保持为 `0`。

相关配置：

```cfg
l4d2_mexp_w_skeet "1.0"
l4d2_mexp_w_melee_skeet "2.0"
l4d2_mexp_w_tongue_cut "0.5"
l4d2_mexp_w_hunter_deadstop "0.2"
l4d2_mexp_w_charger_level "0.2"
l4d2_mexp_w_fast_clear "0.8"
l4d2_mexp_w_smoker_self_clear "0.6"
l4d2_mexp_fast_clear_time "0.75"
```

### 小尸

玩家击杀普通小僵尸的次数。当前权重是 `0.13`，也就是约 8 只小僵尸等于 1 分，用来奖励负责清尸潮的玩家，但仍然不会让刷小僵尸变成唯一主要得分来源。

### Tank

Tank 相关统计是轻量版：

- `坦伤`：玩家对 Tank 造成的伤害，显示为“原始伤害(计分伤害)”；默认 500 点计分伤害约等于 1 分。
- `坦杀`：给 Tank 最后一击，默认 +5 分。
- `坦一`：单只 Tank 中原始伤害最高的玩家，默认 +10 分。
- `石破`：打爆 Tank 石头，默认 +3 分。
- `石中`：被 Tank 石头砸中，默认 -10 分。
- `拳`：站立时被 Tank 拳打中，默认 -4 分。
- `打铁`：站立时被 Tank 打出的车、铁、物理物件压中，默认 -15 分。

这样主要奖励“真的在处理 Tank 的人”，但不会让 Tank 分数完全压过清控、生存和团队配合。

### 口水

站立生还者受到 Spitter 口水伤害会扣分，当前权重是 `0.15`，也就是吃 100 点口水约扣 15 分。倒地或挂边后的口水伤害不计入这个额外扣分，因为此时玩家基本没有主动规避能力。

### Witch

击杀 Witch 默认 +5 分。这个分值故意不高，主要是认可处理 Witch 的贡献，而不是鼓励为了抢分乱开 Witch。

### 清控

玩家击杀正在控制队友的特感时，记为清控。

插件会记录“哪个特感正在控制哪个生还者”。如果控人状态刚被游戏事件清掉，但控人特感在短时间内死亡，也允许算作清控。

相关配置：

```cfg
l4d2_mexp_clear_recent_window "1.0"
```

注意：清控主要统计“击杀控人特感”。单纯推开 Hunter/Jockey、砍断舌头、撞停 Charger，但没有击杀控人特感，通常不会记为清控。

### 承压

被特感控制后，如果这次控制期间没有倒地、没有死亡，最后被救下或控制结束，记为承压。

这个指标用于补偿前排开路玩家。前排可能更容易吃控，但只要没有因为吃控导致倒地或死亡，就不应该被算法过度惩罚。

### 被控

玩家被 Smoker、Hunter、Jockey、Charger 控制的次数。

已经倒地或挂边的人如果再被控，不会继续增加被控次数和被控时间。倒地后的玩家没有反抗能力，这部分不应该造成额外雪崩式扣分。

### 控时

玩家被控制的总秒数。控制时间越长，扣分越多。

### 倒地 / 死亡

倒地和死亡是主要失误惩罚项。前排吃控本身只小扣，但吃控后倒地或死亡会明显扣分。

### 安全屋内倒地 / 死亡

从 `1.5.0` 开始，玩家离开过起点安全区后，再进入 checkpoint 安全屋时，如果在安全屋内倒地或死亡，惩罚会按倍率降低。

当前配置：

```cfg
l4d2_mexp_saferoom_incap_scale "0.10"
l4d2_mexp_saferoom_death_scale "0.10"
```

含义：

- 普通倒地仍按 `l4d2_mexp_p_incap` 扣分。
- 普通死亡仍按 `l4d2_mexp_p_death` 扣分。
- 安全屋内倒地只吃 10% 倒地惩罚。
- 安全屋内死亡只吃 10% 死亡惩罚。
- `!mexp_round` 中会显示 `安倒` 和 `安死`，方便确认触发次数。

注意：当前只处理“已经进入安全屋”的情况，还不处理“离安全屋很近但尚未进入”的情况。后者留作后续改进。

### 友伤

玩家对队友造成的伤害。当前配置为每 10 点友伤扣 1 分：

```cfg
l4d2_mexp_p_ff_damage "0.10"
```

## 调参建议

如果后排只打特感仍然偏高：

```cfg
l4d2_mexp_w_si_damage "0.005"
l4d2_mexp_w_si_kill "0.25"
```

如果前排吃控仍然偏低：

```cfg
l4d2_mexp_w_control_survive "5.0"
l4d2_mexp_p_control "1.0"
l4d2_mexp_p_control_time "0.3"
```

如果分数整体太高：

```cfg
l4d2_mexp_base_score "80.0"
```

如果长期经验变化太快：

```cfg
l4d2_mexp_rating_weight "0.005"
```

如果长期经验变化太慢：

```cfg
l4d2_mexp_rating_weight "0.015"
```
