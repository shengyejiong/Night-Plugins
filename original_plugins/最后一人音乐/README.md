# 最后一人音乐

作者：night  
版本：1.2.0-night

当队友倒地或死亡、全队只剩一名生还者未倒地时，随机选一首音乐，播放给当时在线且未关闭个人收听的真人，包括倒地、死亡和旁观的玩家。最后站着的人可以是真人，也可以是 Bot。

## 游戏内指令

| 指令 | 权限 | 功能 |
| --- | --- | --- |
| `!musicoff` | 所有真人 | 立即停止自己的音乐，并关闭后续自动播放，不影响别人 |
| `!musicon` | 所有真人 | 恢复个人收听，从下一首或下次触发时生效 |
| `!lsmoff` | 配置权限管理员 | 关闭全服音乐及自动重播，保留每人的收听偏好 |
| `!lsmon` | 配置权限管理员 | 恢复全服音乐，仍跳过个人关闭的玩家 |
| `!lsm_status` | 所有玩家和服务端控制台 | 查询人数、曲库、循环、个人开关及播放状态 |

个人开关通过 SourceMod 自带的 ClientPrefs（玩家偏好存储）记住，换图和重新连接后仍然有效。偏好尚未读取完成的玩家不会提前收到音乐，避免已关闭的玩家进服时短暂听到声音。

管理员全服开关调整运行中的 `l4d2_lsm_enable`，换图重新执行配置后以配置文件为准；需要长期关闭时，将 `cfg/sourcemod/l4d2_last_survivor_music.cfg` 中的该参数设为 `0`。

## 触发与停止规则

- 生还者队伍至少有两名成员，包含真人、Bot、倒地和已死亡成员；单人独自游玩不触发。
- “站立”指存活、未倒地、未挂边。被特感控制但尚未倒地仍计入未倒地人数。
- 一名站立者加其他倒地或死亡队友时触发，不要求倒地队友全部死亡。
- 同一帧的状态事件会合并，延迟到下一帧读取最终人数；全员同一帧倒地、站立人数为零时不播放。
- 开始播放时默认用 1.5 秒淡入。恢复到至少两人站立、站立人数降到零、回合结束、团灭或关闭插件时，默认用 1 秒淡出再停止。
- 换图、新回合开始或卸载插件时直接停止并清理计时器，避免旧回合音乐残留。
- 默认开启自动重播：歌曲结束后重新检查人数，仍然只剩一人站立时随机播放下一首；只有一首时从头重播这一首。
- `l4d2_lsm_repeat` 设为 `0` 后，每次连续的最后一人状态只播放一首；恢复多人站立后再次陷入最后一人状态时，仍可重新触发。
- 有多首歌曲时，本地图相邻两次播放尽量避免抽中同一首。状态期间新加入或重新打开个人开关的玩家，从下一首或下次触发时开始收听，不从歌曲中段接入。
- 如果淡出尚未结束就再次只剩一人，会沿同一首歌曲的当前进度恢复音量，不从头重播或叠加。
- 曲库填入歌曲时长后，会在歌曲自然结束前淡出，并在结束后按自动重播开关决定是否继续。
- 个人关闭的玩家不会被淡入、自动重播或全服重新开启强制打开。全体真人都关闭或尚未载入偏好时，不创建无人收听的播放。
- 完全停止后仍从头播放，暂不支持暂停在某个秒数后精确续播。
- 同时使用减难插件时，如果复活使站立人数恢复到两人及以上，本插件会自动停止音乐。

通过倒地、死亡、救起、复活和队伍变化事件检查人数，同时每 0.25 秒检查一次，兼容其他插件直接修改玩家状态。本插件不修改玩家生命、复活、装备或减难阶段。

## 安装和文件

需要 Left 4 Dead 2、SourceMod 1.12 和自带的 SDKTools、ClientPrefs，无需 Left 4 DHooks 或其他第三方插件。

将本目录按以下相对路径合并到服务器的 `left4dead2/`：

| 文件 | 用途 |
| --- | --- |
| `addons/sourcemod/plugins/l4d2_last_survivor_music.smx` | 运行插件 |
| `addons/sourcemod/configs/l4d2_last_survivor_music.cfg` | 曲库和歌曲显示名 |
| `cfg/sourcemod/l4d2_last_survivor_music.cfg` | 开关、音量、淡入淡出时间、自动重播、聊天提示 |
| `sound/night_laststand/*.mp3` | 候选音乐文件 |

源码位于 `addons/sourcemod/scripting/l4d2_last_survivor_music.sp`。首次安装及调整曲库、增加歌曲后，建议换图再测试。

目前曲库已加入 `rainloveDJ.mp3`，约 197.2 秒、44.1 kHz、主要为 128 kbps，文件约 3 MB。歌曲显示名为 `rainloveDJ`，可在曲库文件中修改。只有这一首时，每次都会播放它；添加更多曲目后会随机选择。

## 推荐音频格式

- 首选 **MP3**，采样率 **44.1 kHz / 44100 Hz**。
- 比特率推荐 **128～192 kbps CBR（恒定比特率）**，双声道。
- 建议单首不超过 5 MB；为了减少进服下载时间，优先剪成约 30～90 秒的片段。
- 也接受 WAV，建议使用 **44.1 kHz、16 位 PCM**；文件通常比 MP3 大得多。
- AAC、M4A、FLAC、OGG 不能直接改后缀使用，需要转换编码。
- 使用小写英文文件名，例如 `music_01.mp3`。路径不用空格、中文或特殊字符，歌曲显示名可以写中文。
- MP3 应先正常解码，避免音量过大、削波或包含很长的开头静音。

## 添加曲目

1. 把音乐放入服务器的 `left4dead2/sound/night_laststand/`。
2. 同步这些音乐到 FastDL 的相同相对目录。
3. 编辑 **曲库文件** `addons/sourcemod/configs/l4d2_last_survivor_music.cfg`，例如：

```text
"LastSurvivorMusic"
{
    "rainloveDJ"
    {
        "path" "night_laststand/rainloveDJ.mp3"
        "duration" "197.19"
    }
    "独自迎战"
    {
        "path" "night_laststand/music_02.mp3"
        "duration" "90.0"
    }
}
```

4. 换图，让玩家重新连接并完成下载。插件会预缓存全部有效曲目并加入客户端资源下载表。

`duration` 填歌曲实际时长（秒），用于自然结束前的淡出和自动重播，改换音频后应重新核对；填 `0` 或省略时，无法判断歌曲何时结束，不会按时长淡出或自动重播，但退出最后一人状态时仍然淡出。不要调用 SourceMod 已弃用的 `GetSoundDuration()` 获取 MP3 时长。

两个配置文件同名但位置和用途不同：`addons/sourcemod/configs/` 下填写曲库，`cfg/sourcemod/` 下调整开关和音量。

## FastDL 与客户端要求

音乐是提前下载到客户端后播放。服务器插件不会把服务器里的 MP3 实时流播给玩家；仅上传 SMX 无法让没有歌曲文件的玩家听到音乐。

需要准备 FastDL（使用 HTTP 提供游戏资源的快速下载服务）。假设 `sv_downloadurl` 指向 `http://你的资源服务器/left4dead2/`，则对应歌曲应能通过 `http://你的资源服务器/left4dead2/sound/night_laststand/music_01.mp3` 下载。

服务器示例：

```text
sm_cvar sv_allowdownload "1"
sv_downloadurl "http://你的资源服务器/left4dead2/"
```

玩家需要将游戏“自定义服务器内容”设为“全部允许”。临时本机测试也可以先手动将同一份音乐放入测试客户端的 `left4dead2/sound/night_laststand/`。

部分 L4D2 服务器会把 `sv_allowdownload` 隐藏，直接输入时提示 Unknown command；上面的 `sm_cvar` 写法通过 SourceMod 设置该变量。

不存在的歌曲、路径不合法或预缓存失败的歌曲会被跳过，并在 SourceMod 错误日志中说明。加入新歌曲不会补发给已经进服的客户端，需换图或重新连接完成下载。

## 参数和查询

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `l4d2_lsm_enable` | `1` | 是否启用，关闭后按配置淡出 |
| `l4d2_lsm_volume` | `0.45` | 0～1 的播放音量，下次播放生效 |
| `l4d2_lsm_fade_in` | `1.5` | 0～15 秒的淡入时间，0 表示直接播放 |
| `l4d2_lsm_fade_out` | `1.0` | 0～15 秒的淡出时间，0 表示立即停止 |
| `l4d2_lsm_repeat` | `1` | 歌曲结束后仍只剩一人时，自动随机下一首；0 表示本次状态只播一首 |
| `l4d2_lsm_announce` | `1` | 是否聊天提示歌曲和最后站立者 |

输入 `!lsm_status` 查看当前曲库数量、生还者总数、站立人数、当前音量、循环配置及个人开关，所有玩家均可查询。客户端本身的静音和音量设置仍然影响听感。淡入淡出只改变本插件音乐，不修改枪声、脚步声或语音的整体音量。

## 实测场景

| 场景 | 预期 |
| --- | --- |
| 1 人站立、1 人死亡、2 人倒地 | 随机播放一首给全体真人 |
| 1 人站立、其他人全部倒地 | 播放，无需等待倒地者死亡 |
| 唯一站立者是 Bot | 同样触发，播放给全体真人 |
| 全员同一帧倒地 | 不播放 |
| 正在播放时唯一站立者倒地 | 默认用 1 秒淡出后停止 |
| 救起队友、恢复 2 人站立 | 淡出，结束后下次仅剩一人时重新抽歌 |
| 淡入尚未完成就救起队友 | 从当前音量淡出，不突然跳到最大音量 |
| 淡出期间再次只剩一人 | 继续同一首歌曲，从当前音量淡入 |
| 配置淡入或淡出为 0 | 对应过程立即完成 |
| 配置歌曲时长且歌曲接近结束 | 自然结束前淡出，自动重播开启时再按实际人数决定是否播放下一首 |
| 一直只有 1 人站立 | 每首结束后自动重播，不在每次检测时从头重播，不叠加歌曲 |
| 自动重播关闭、播完一首后仍只剩一人 | 本次最后一人状态不再开始新曲目 |
| 自动重播即将开始但全员同一帧倒地 | 不开始下一首 |
| 某人输入 `!musicoff`，随后发生自动重播 | 此人立即静音且不收到下一首，其他人继续收听 |
| 某人输入 `!musicon`，已有其他人在听一首歌 | 该玩家从下一首或下次触发开始收听 |
| 已关闭个人音乐，随后换图或重新连接 | 仍保持个人关闭 |
| 管理员输入 `!lsmoff`，仍处于最后一人状态 | 全服淡出后不再自动开始，直到重新开启或重新执行配置 |
| 管理员重新开启，全体或部分人曾个人关闭 | 仍尊重每人关闭偏好 |
| 队伍只有 1 名成员 | 不触发 |
| 曲库为空 | 不播放，`!lsm_status` 显示曲库 0 |

## 1.0.0-night

- 初版，包含最后一人状态检测、全体真人播放、随机选曲、恢复时停止和曲库配置。

- 增加可配置的淡入和淡出，只调节本插件音乐音量。
- 防止反复检查人数时重置淡出，也支持淡出期间恢复同一首歌曲的音量。
- 加入 `rainloveDJ.mp3` 及其时长配置，支持歌曲自然结束前淡出。
- 仍需在游戏中验证实际音频、资源下载和音量变化效果。

## 1.2.0-night

- 增加 `l4d2_lsm_repeat`，在最后一人状态持续时自动随机下一首；仅一首时自动重播。
- 增加 `!musicoff` / `!musicon`，通过玩家偏好存储记住个人关闭设置，循环及淡入均遵守个人选择。
- 增加管理员全服开关 `!lsmoff` / `!lsmon`。
- 查询显示自动重播、允许收听人数和个人开关；全体关闭时停止无人收听的音乐。
- 精确暂停续播暂未实现，完全停止后新播放仍然从头开始。
