# 更新日志

## 1.3.10-night - 2026-08-26

- 修复团灭重开后偶发不再启动自定义刷特 Timer 的问题。
- `round_start` 会重置回合刷新状态，并以低频 Timer 检查生还者是否已经离开起点安全区。
- 正常收到 Left 4 DHooks 离开安全区回调时会立即取消兜底检查，不会重复启动刷特 Timer。
- 人数、批量、种类、权重和刷新间隔算法保持不变。

## 1.3.9-night - 2026-08-26

- 移除特感客户端断开后 `0.2` 秒立即补刷的逻辑。
- 修复普通特感死亡或被踢出后过早补位、实际绕过 `ss_time_min` / `ss_time_max` 刷新节奏的问题。
- 外部插件一次处死全部特感后，重新交由原版周期生成 Timer 决定下一批生成时间。
- 保留真实空槽检查、满槽空转保护和单补刷 Timer 修复。
- 保留原版动态特感上限及单批补刷数量。

## 1.3.8-night - 2026-08-23

- 新增真实客户端空槽检查，满槽时停止无效出生点搜索和 Bot 创建。
- 保留原版动态特感上限及单批补刷逻辑，不强制限制 `ss_spawn_size`。
- 修复自动处死多只特感时可能叠加多个补刷 Timer 的问题。
- 新增特感客户端断开后的单 Timer 补位。
- 修复出生点搜索失败时可能复用上一次有效位置的问题。
- 使用独立文件名 `specialspawner_fullslots`，继续读取原来的 `specialspawner.cfg`。
- 保留未经修改的 1.3.7 源码、SMX 和默认 CFG，方便回滚。
