# L4D2 Multi-Function X Menu（刷特感控制菜单）

作者：らくらく安楽死、night
版本：3.1.0-night

通过全服投票开关多特插件，并调整基础特感数量与刷新间隔。

菜单会实时读取多特插件状态，并显示当前每批刷特数、场上特感上限与刷新时间区间。

## 游戏内指令

- `!x`：打开特感配置投票菜单。

## 注意事项

- 依赖 `l4d2_nativevote` 和 `specialspawner_fullslots.smx`。
- 菜单通过加载或卸载 `specialspawner_fullslots.smx` 来开关多特；状态检测和关闭操作兼容旧文件名 `specialspawner.smx`。
- “基础特感数量”会同时修改4人及以下时的场上上限和每批刷特数；多人动态数量按刷特插件本身的算法重新计算。
- “各类特感上限”允许任意玩家直接调整 Smoker、Boomer、Hunter、Spitter、Jockey 和 Charger 的场上上限，范围为 `0～15`，无需投票。
- 单类上限设为 `0` 表示禁止生成该类特感；允许六类全部为 `0`。降低上限不会处死已经存活的特感，只影响后续生成。
- 单类上限仅在当前地图生效，团灭重开仍保留；换图后以 `specialspawner.cfg` 中的配置为准。

## 3.1.0-night 更新

- 在 `!x` 的特感配置中增加六类特感上限菜单，所有玩家均可直接修改。
- 设置结果会向全服通报；六类全部为 `0` 时提示普通特感已经暂停生成。

## 3.0.1-night 更新

- 加载或卸载多特插件后改为延迟确认实际运行状态，避免操作已经成功却提示失败。
- 首次确认未达到目标状态时只重试一次，第二次确认仍失败才提示管理员检查。

## 3.0 更新

- 修复插件改名后投票结果与菜单开关状态不一致的问题。
- 显示实时的“每批数量 / 场上上限 / 刷新区间”，不再把4人基础值误报成当前配置。
- 修正多人时每批刷特数的计算方式，`ss_extra_size` 按“每增加多少名玩家，每批增加1只”处理。
