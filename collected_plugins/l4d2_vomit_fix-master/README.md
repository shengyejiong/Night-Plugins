# L4D2 Vomit Fix

作者：lakwsh

包含两个插件：

- `l4d2_vomit_fix` 1.1.1：修复非 30 Tick 对抗模式下 Boomer 喷吐距离异常的问题。
- `l4d2_a2s_fix` 1.0.2：`a2s_patch` 的 SourceMod 插件实现，仅在使用 `steam_bypass` 等相关功能时按需启用。

## 游戏内指令

无，插件加载后自动生效。

## 注意事项

- `.smx` 必须与同名 GameData 文件配套使用。
- 安装 `l4d2_a2s_fix` 或同类 `a2s_patch` 后，服务器端口号不得大于 `32767`。
