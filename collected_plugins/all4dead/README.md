# All4Dead 2

原版作者：grandwazir  
改进版维护：HarryPotter

让管理员无需开启 `sv_cheats`，即可通过管理菜单控制 AI Director（导演系统），并生成武器、物品、特殊感染者等内容。

## 游戏内指令

- `!admin`：打开 SourceMod 管理菜单，然后选择 `ALL4DEAD`。

## 注意事项

- 需要管理员权限。
- 本收集版本需要 `all4dead2.smx` 与 `all4dead2.txt` GameData 配套使用。
- 原项目：<https://github.com/fbef0102/L4D1_2-Plugins/tree/master/all4dead2>
