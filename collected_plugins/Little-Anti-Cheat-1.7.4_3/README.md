# Little Anti-Cheat（Lilac）

作者：J_Tanzanite  
版本：1.7.4  
原项目：<https://github.com/J-Tanzanite/Little-Anti-Cheat>

用于检测和处理瞄准、连跳、宏、异常插值、非法 CVar、聊天与名称异常等作弊或滥用行为。

## 游戏内指令

无，插件在后台自动检测。

## 注意事项

- 首次运行会生成 `cfg/sourcemod/lilac_config.cfg`，检测与处罚方式应在正式启用前自行检查。
- 检测日志写入 `addons/sourcemod/logs/lilac.log`。
- 1.7.4 版本已移除 L4D1/L4D2 的角度作弊检测。
- SourceBans++、MaterialAdmin 和数据库日志均为可选功能。
