# L4D HOTs（针药缓慢回血）

作者：ProdigySim、CircleSquared、Forgetest  
版本：2.4

把止痛药和肾上腺素的临时生命值改为分段缓慢恢复，而不是使用后立即获得全部临时生命值。

## 游戏内指令

无，启用后自动生效。

## 注意事项

- 依赖 Left 4 DHooks。
- 止痛药与肾上腺素的缓慢恢复默认均为关闭状态，需要分别设置 `l4d_pills_hot 1` 和 `l4d_adrenaline_hot 1`。
- 恢复间隔、单次恢复量和总恢复量可通过同名前缀的 CVar 调整。
- 原项目：<https://github.com/SirPlease/L4D2-Competitive-Rework>
