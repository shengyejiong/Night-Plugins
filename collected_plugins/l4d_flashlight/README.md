# Flashlight Package（附加手电筒）

作者：SilverShot  
版本：2.34  
原项目：<https://forums.alliedmods.net/showthread.php?t=173257>

为玩家附加可自定义颜色的手电筒。本收集包的配置仅允许死亡生还者使用个人手电，活着的玩家默认不能使用。

## 游戏内指令

- `!light`：开关手电筒，也可在后面填写颜色。
- `!lightmenu`：打开手电筒颜色菜单。
- `!lightbow`：切换彩虹灯；当前配置默认禁用该功能。
- `!lightclient <目标>`：管理员为指定玩家设置手电筒，需要 Root 权限。

## 注意事项

- 默认使用 2026 年重新编译的 SMX；原始 SMX 保存在 `alternate_builds/original`，不要同时加载。
