# Hunter Pounce Damage（猎人飞扑伤害）

作者：SilverShot  
版本：1.1d  
原项目：<https://forums.alliedmods.net/showthread.php?t=320024>

解除游戏模式限制，让 Hunter 的远距离飞扑奖励伤害在所有模式中生效。

## 游戏内指令

无，插件加载后自动生效。

## 注意事项

- `l4d2_pounce_damage.smx` 必须与同名 GameData 配套使用。
- 插件通过内存补丁实现，更新或替换后建议完整重启服务器。
- 游戏更新后如果出现 `byte mis-match`，说明 GameData 已失效，需要更新。
